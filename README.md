# 🕋 আল-মিহরাব: নামাজের সময়সূচী ও কিবলা কম্পাস (Al-Mihrab: Prayer Times & Qibla Compass)

আল-মিহরাব একটি অত্যন্ত আধুনিক, নিখুঁত এবং চক্ষু-বান্ধব ওয়েব অ্যাপ্লিকেশন যা প্রতিদিনের ইসলামিক ইবাদত এবং আমলসমূহকে সহজতর করার জন্য ডিজাইন করা হয়েছে। এটি সম্পূর্ণ রেসপন্সিভ এবং মোবাইল-ফ্রেন্ডলি।

---

## 🇧🇩 বাংলা ফিচার নির্দেশিকা (Bengali Feature Guide)

### ১. নিখুঁত নামাজের সময়সূচী (Accurate Prayer Times)
*   **ডিস্ট্রিক্ট ভিত্তিক ও জিপিএস স্থানাঙ্ক:** বাংলাদেশের ৬৪টি জেলার ডেটাবেজ যুক্ত আছে। এছাড়াও নিখুঁত জিপিএস ট্র্যাকিংয়ের মাধ্যমে অফলাইনে বা অনলাইনে যেকোনো নির্দিষ্ট অবস্থানের সঠিক নামাজের সময় হিসাব করা যায়।
*   **ফিজিক্যাল ক্যালকুলেশন মেথডস:** মুসলিম ওয়ার্ল্ড লীগ (MWL - যা বাংলাদেশে অত্যন্ত গ্রহণযোগ্য), ISNA, করাচি ইউনিভার্সিটি ও উম্মুল কুরা সহ বিভিন্ন গণনা পদ্ধতি সমর্থিত।
*   **আসর নামাযের মাযহাব হিসাব:** ইমাম হানাফী (২ গুণ ছায়া), শাফেয়ী, মালেকী এবং হাম্বলী (১ গুণ ছায়া) ফিকাহ অনুযায়ী আসরের ওয়াক্ত নির্ধারণের পূর্ণ সুবিধা রয়েছে।
*   **নিষিদ্ধ ও মকরুহ সময় নোটিফিকেশন:** সূর্যোদয়, মধ্যাহ্ন (জাওয়াল) ও সূর্যাস্তের সময় নামাজের নিষিদ্ধ ওয়াক্তের লাইভ রিয়েল-টাইম সেকশন ডিসপ্লে।

### ২. গাইরো-স্মুথ কিবলা কম্পাস (Jitter-Free Qibla Compass)
*   **অ্যাডভান্সড ভেক্টর ফিল্টারিং (Vector Smoothing):** সাধারণ কম্পাসগুলোর মতো এটি ফোনে কাঁপে না (কাপাকাপি করে না)। উন্নত 2D ট্রাইগোনোমেট্রিক ভেক্টর এবং লো-পাস ডিজিটাল ফিল্টারিংয়ের মাধ্যমে অ্যান্ড্রয়েড ক্রোম ও আইওএস সাফারিতে কম্পাসের ঘূর্ণন করা হয়েছে অত্যন্ত মসৃণ এবং স্বাভাবিক।
*   **ডার্ক ও লাইট থিম অ্যাডাপ্টিভ ডায়াল:** কম্পাস রোজ বা ডায়ালটি ডার্ক এবং লাইট মুডে নিজের কালার পরিবর্তন করে যা চোখকে প্রশান্তি দেয়।
*   **জিপিএস ভিত্তিক কাবা দূরত্ব:** আপনার বর্তমান অবস্থান থেকে মক্কার পবিত্র কাবা শরীফের সঠিক দূরত্ব (কিলোমিটারে) এবং কোণ (Bearing Degree) রিয়েল-টাইমে গণনা করে।

### ৩. অটো-অ্যাডভান্স ডিজিটাল তাসবিহ (Auto-Advance Digital Tasbih)
*   **স্মার্ট কাউন্টার লুপ:** সুবহানাল্লাহ (৩৩), আলহামদুলিল্লাহ (৩৩) এবং আল্লাহু আকবার (৩৪) সহ বিভিন্ন জিকিরের রেডিমেড প্রিসেট রয়েছে।
*   **অটো-পরবর্তী জিকির ট্রানজিশন (Auto Next Tasbih):** কোনো একটি প্রিসেট সম্পূর্ণ হওয়ার সাথে সাথে (যেমন ৩৩ সম্পন্ন হলে) একটি চমৎকার সুরের নোটিফিকেশন বাজবে এবং ৯০০ মিলি-সেকেন্ডের মধ্যে এটি স্বয়ংক্রিয়ভাবে পরবর্তী জিকিরে সুইচ করবে। ফলে স্ক্রিনে বারবার হাত দিয়ে পরিবর্তন করার প্রয়োজন নেই, একটানা জিকির চালিয়ে যাওয়া সম্ভব।
*   **কাস্টম টার্গেট:** ব্যবহারকারী চাইলে নিজের সুবিধামতো কাস্টম সংখ্যা সেট করে জিকির করতে পারেন।

### ৪. চাঁদ সংশোধনযোগ্য হিজরি ক্যালেন্ডার (Adjustable Lunar Hijri Calendar)
*   **সৌদি-বাংলাদেশ ডে-অফসেট:** হিজরি ক্যালেন্ডার সাধারণত কুয়েতি সমীকরণ অনুযায়ী চলে যা সৌদি আরবের চাঁদ দেখার সাথে মিলে। বাংলাদেশ যেহেতু সাধারণত একদিন পরে চাঁদ দেখতে পায়, তাই সেটিংসে **`-২` থেকে `+২` দিন হিজরি অফসেট** পরিবর্তনের ব্যবস্থা আছে। বাংলাদেশে সঠিক তারিখের জন্য ডিফল্টভাবে **`-১` দিন পিছিয়ে** হিসাব করার ব্যবস্থা স্বয়ংক্রিয়ভাবে কার্যকর থাকে।
*   **ইসলামিক দিবসসমূহ:** শবে বরাত, শবে কদর, রমজান এবং দুই ঈদের মতো গুরুত্বপূর্ণ দিনগুলো ক্যালেন্ডারে হাইলাইট করা থাকে।
*   **বাংলা বর্ষপঞ্জি:** সংশোধিত জাতীয় বাংলা ক্যালেন্ডারও একই সাথে প্রদর্শিত হয়।

### ৫. কাস্টমাইজ লেখার সাইজ (Custom Typography Scale)
*   **সব বয়সের ব্যবহারকারীর জন্য উপযোগী:** সেটিংসে চারটি অক্ষরের মাপ (`sm`, `md`, `lg`, `xl`) যুক্ত করা হয়েছে। এটি পরিবর্তন করলে অ্যাপ্লিকেশনের সব লেখা, আরবি হরফ, বাংলা এবং ইংরেজি অনুবাদ তাৎক্ষণিকভাবে ছোট বা বড় আকারে প্রদর্শিত হবে যা বয়োজ্যেষ্ঠদের জন্য অত্যন্ত সুবিধাজনক।

### ৬. চক্ষু-বান্ধব আভিজাত্যময় থিম (Premium Eye-Safe UI Styles)
*   **উজ্জ্বল ছোপ-ছোপ দাগ বর্জন:** পূর্বের বিরক্তিকর এবং চোখে অস্বস্তি সৃষ্টিকারী ঘন ডট প্যাটার্ন ও নিয়ন হলুদ রঙ বাদ দেওয়া হয়েছে।
*   **শান্তিময় রঙের কম্বিনেশন:**
    *   **লাইট মোড (Light Mode):** নরম এবং প্রিমিয়াম অফ-হোয়াইট (`#f8faf7`) ক্যানভাস।
    *   **ডার্ক মোড (Dark Mode):** গভীর মখমলি সবুজ ও মখমলি ডার্ক ওভলিসিন (`#070c08`) থিম এবং নরম মেটালিক গোল্ডেন (`#d4a323`) বর্ডার যা রাতের বেলা বা কম আলোতে চোখের স্ট্রেন কমায়।

### ৭. অন্যান্য বিশেষ সুবিধাসমূহ:
*   **নামাজ ট্র্যাকার (Prayer Attendance Tracker):** প্রতিদিনের ৫ ওয়াক্ত সালাতের হাজিরার হিসাব যা সপ্তাহ এবং মাসের পারফরম্যান্স রেটিং গ্রাফ আকারে দেখায়।
*   **যাকাত ক্যালকুলেটর (Zakat Calculator):** নিসাব এবং বর্তমান সোনা, রূপা ও জমানো টাকার হিসাব অনুযায়ী যাকাত বের করার টুল।
*   **হাদিস ও ফজিলত (Hadith & Hijri Virtues):** প্রতিদিনের আরবি মাসের ফজিলত ও অটো দৈনন্দিন হাদিস/দোয়া।

## 🇺🇸 English Features Reference (English Guide)

### 1. High-Fidelity Prayer Times & Settings
*   **Global Coordinate Parsing:** Complete pre-loaded database of Bangladeshi districts with optional real-time GPS coordinates fetching.
*   **Juristical Madhab Configurations:** Supports Sunni traditional schools—Hanafi (double shadow calculation factor), Shafi'i, Maliki, and Hanbali (single shadow factor).
*   **Standard Astrological Methods:** Includes MWL (recommended for Bangladesh), ISNA, Karachi, Egypt, and Umm Al-Qura conventions.

### 2. Auto-Smoothed Digital Qibla Compass
*   **Low-Pass Vector Angle Filter:** Solves browser compass shaking issues! A mathematical 2D unit vector coordinates averaging algorithm eliminates jittering on mobile devices, providing ultra-smooth orientation feedback.
*   **Responsive Theme Dial:** Automatically changes layout dial borders and backgrounds dynamically on light/dark theme shifts.
*   **Precision Angle:** Yields real-time bearing angle and distance to Mecca in kilometers.

### 3. Continuous-Looping Digital Tasbih
*   **Standard Cycle Presets:** Built-in loops for Subhanallah (33), Alhamdulillah (33), Allahu Akbar (34), and custom counting modes.
*   **Auto-Advance Loop Transition:** Once a preset is completed, a chord chime notification alerts the user, and the tracker automatically advances to the next preset in 900ms. Perfect for fluid, one-tap spiritual chanting.

### 4. Customizable Lunar Day Offset Hijri Calendar
*   **Offset Adjustment Selector:** Since lunar sightings in South Asia are typically delayed relative to Makkah calculations, users can customize a **`-2 to +2 day offset`** directly inside Settings (-1 day is auto-preset for Bangladesh users).
*   **Islamic Holiday Annotations:** Color-coded circles pointing out Ramadan, Eid-ul-Fitr, Eid-ul-Adha, Laylat-al-Qadr, etc.

### 5. Custom Typography Scales
*   **Accessible Typography:** Four customized font and text scale factors (`sm`, `md`, `lg`, `xl`) are integrated under System Settings. Changing this instantly scales Quranic text, translations, and dashboard elements globally.

### 6. Eye-Safe Velvet Lux Themes
*   **Visual Optimization:** All high-contrast busy dotted background graphics and neon-yellow aesthetics have been replaced.
*   **Calming Palettes:** Uses premium cream-beige elements (`#f8faf7`) in Light Mode and deep emerald-black velvet values (`#070c08`) in Dark Mode to provide ultimate optical safety and premium aesthetics.

## 🛠️ প্রযুক্তিগত তথ্যাবলী (Technical Specifications)

*   **ফিজিক্যাল ফ্রেমওয়ার্ক:** React 18+ with Vite
*   **টাইপোগ্রাফি ও প্রোগ্রামিং ল্যাঙ্গুয়েজ:** TypeScript (Strict compliance)
*   **স্টাইল ইঞ্জিন:** Tailwind CSS (Utility direct implementation)
*   **আইকন লাইব্রেরি:** Lucide React
*   **অ্যানিমেশন ইঞ্জিন:** Framer Motion (`motion/react`)
*   **অডিও এপিআই:** Web Audio API (No large file downloads needed, synthetic clean chimes)

## 🚀 কীভাবে চালু করবেন (How to Run)

১. প্রথমে প্রয়োজনীয় ডিপেন্ডেন্সি ফাইল ইনস্টল করুন:
```bash
npm install
```

২. ডেভেলপমেন্ট সার্ভার চালু করতে নিম্নোক্ত কমান্ডটি ব্রাউজারে রান করুন:
```bash
npm run dev
```

৩. প্রোডাকশন সংস্করণ তৈরি করতে ব্যবহার করুন:
```bash
npm run build
```
